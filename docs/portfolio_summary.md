# Portfolio summary

## Project

**PrepInterview AI Product Analytics Prototype** is a Tableau and SQL portfolio
case study built around the real workflow of PrepInterview AI: job capture,
AI-generated prep plans, notes, exams, mock interviews, and AI generation.

The dataset is deterministic synthetic demonstration data. It is designed to
show analytics design and implementation skills, not customer traction or
production performance.

## Skills demonstrated

- Tableau dashboard design and Tableau Public publishing
- SQL analysis of activation funnels, retention cohorts, feature adoption,
  learning outcomes, and AI reliability
- Product event taxonomy and relational event-data modeling
- KPI definitions, data-quality validation, and reconciliation
- Reproducible synthetic-data generation with public-safe aggregate extracts
- Stakeholder-focused data storytelling with explicit interpretation limits

activation, revenue, experimentation, or business-impact results. The public
dashboard and README must keep the synthetic-data disclosure visible.
